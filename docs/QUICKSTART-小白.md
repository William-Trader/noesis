# 三分钟上手（不用懂技术）

你不需要记命令。把下面的话**原样发给你的 AI agent**，它就会照做。

## 场景一：第一次打开这个库

发给 agent：

```
这是我的知识库：<把文件夹拖进来，或者粘贴路径>
请先读 Noesis 仓库的 docs/HANDOVER.md，然后帮我体检一遍，
告诉我：库结构对不对、有没有散落的文件、索引是不是最新的。
不要动任何文件。
```

agent 会跑三条只读检查，然后给你一份体检结论。

## 场景二：让 agent 一键整理

发给 agent：

```
帮我一键整理这个知识库：<路径>
先给我看整理计划（哪些文件移到哪、为什么），我确认后你再动手。
整理完把「移动了什么、跳过什么、怎么撤销」告诉我。
```

背后发生的事：

1. agent 调 `noesis tidy <库>`，**只出计划**；
2. 你回一句「可以」，它才加 `--yes` 执行；
3. 每一步都写进映射表 `_重组映射表-*.csv`，用 `noesis undo` 可以整批撤销；
4. 目标位置已有同名文件时**跳过**，不覆盖、不删除。

## 场景三：把库带走，再带回改动

带走（插上移动硬盘后）：

```
把这个知识库打包到移动硬盘：<库路径>
```

对应命令：`noesis library pack <库> --out /Volumes/你的盘/知识库.tar.gz`
（可重建的索引、node_modules、venv 不会被打包，所以很小）

带回来（在原来那台机器上）：

```
移动硬盘上的库我改过了，把更新的文件拷回来：<库路径>，副本在 <盘上的目录>
先给我看会覆盖哪些文件，我确认后再写。
```

对应命令：

```bash
noesis sync <库> --from <盘上的目录> --dry   # 先看差异
noesis sync <库> --from <盘上的目录>         # 确认后回写
```

规则：只回写副本里更新/新增的文件；覆盖前把旧文件备份到
`05-归档-archive/_sync-backup-<时间>/`；相同内容跳过；从不删除。

## 常用的一句话

| 你说 | agent 会做 |
|---|---|
| 「找一下报销流程」 | 语义+关键词检索，返回文件和段落 |
| 「这个库健康吗」 | 体检 + 索引新鲜度 |
| 「刚才那步撤销」 | 按映射表反向还原 |
| 「把这个库放到新电脑上」 | 打包 → 解压 → 重新建索引 |

## 三个名词，看懂就够

- **索引**：为了搜索快而生成的缓存，放在 `.noesis/`，删了会自动重建，不是你的资料。
- **映射表**：每次整理的移动清单，`_重组映射表-*.csv`，撤销靠它。
- **库志**：操作流水 `_库志.jsonl`，谁在什么时候做了什么，可追溯。

其它细节：`docs/HANDOVER.md`（给 agent 的完整交接契约）。
